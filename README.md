*"Random-password-generator" - это GUI-приложение «Random Password Generator» с возможностью настройки параметров пароля, сохранением истории и Git.
## Требования для запуска 
Что нужно установить на компьютер: 
- Python 3.10 или выше
- Библиотеки: `pip install matplotlib requests`
